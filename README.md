# Spellfold public pages

Static support and privacy pages: https://nw-b.github.io/spellfold-support/

Hand-written HTML and CSS with one illustration (`spellfold.jpg`, the app icon) and a small `icon.png` for the header and browser tab. No build step, npm dependencies, server, JavaScript, web fonts, cookies or tracking scripts.

Edit index.html, privacy/index.html or style.css locally, commit and push main. GitHub Pages publishes from the repository root. Every internal link and asset path starts with `/spellfold-support/`, so keep the repository named `spellfold-support`. Keep app source, credentials, review contacts and signing files out of this public repository.

When the app's data practices change, update privacy/index.html and its "Updated" date in the same commit.
